# Weather App

A simple command-line Weather App built with Python that fetches real-time weather information using the WeatherAPI.

## Features

- Search Weather by City
- Current Temperature
- Feels Like Temperature
- Humidity
- Wind Speed
- Weather Condition
- Error Handling

## Requirements

Install the required package:

```bash
pip install requests
```

## Run the Project

```bash
python Weather_App.py
```

## 🔑 API Key

This project uses **WeatherAPI**.

1. Create a free account at:

https://www.weatherapi.com/

2. Copy your API key.

3. Replace:

```python
API_KEY = "YOUR_API_KEY" #Eg: API_KEY = "4d77******************************"
```

with your own API key, Else the program will not work.
