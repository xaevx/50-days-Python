# Quiz Application

A simple command-line **Quiz Application** built with Python. Test your knowledge by answering multiple-choice questions and receive your final score at the end.

## Features

- Multiple Choice Questions
- Instant Answer Validation
- Final Score & Percentage
- Performance Feedback
- Simple CLI Interface

## Run the Project

```bash
python Quiz_Application.py
```

## Modules Used

- Python 3

## What i learned

- Lists
- Dictionaries
- Loops
- Conditional Statements
- User Input
- String Manipulation
- Basic Scoring System

> **Note:** Questions are hardcoded in the program. You can easily add more by updating the `questions` list.
