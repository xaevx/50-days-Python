# 🔍 Binary Search Visualizer

A simple command-line **Binary Search Visualizer** built with Python. The program demonstrates how the Binary Search algorithm works by displaying each step of the search process.

## Features

- Binary Search Algorithm
- Step-by-step Visualization
- Shows Left, Right & Middle Index
- Search Result
- Input Validation

## Run the Project

```bash
python Binary_Search_Visualizer.py
```

## Modules Used

- Python 3

## What i learned

- Binary Search
- Functions
- Lists
- Loops
- Conditional Statements
- Algorithm Visualization
- User Input
- Exception Handling

> **Note:** Binary Search works only on **sorted (ascending) lists**.
