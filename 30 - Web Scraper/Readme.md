# Web Scraper

A simple command-line **Web Scraper** built with Python that extracts the title and headings from a web page using **BeautifulSoup**.

## Features

- Fetch Website Content
- Display Page Title
- Extract H1, H2 & H3 Headings
- Input Validation
- Error Handling

## Requirements

Install the required packages:

```bash
pip install requests beautifulsoup4
```

## Run the Project

```bash
python Web_Scraper.py
```

## Example

```
Enter Website URL:
https://www.python.org

Page Title :
Welcome to Python.org

Headings

1. Functions Defined
2. Get Started
3. Downloads
4. Documentation
```

## Modules Used

- Python 3
- Requests
- BeautifulSoup4
