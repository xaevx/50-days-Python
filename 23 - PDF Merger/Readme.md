# PDF Merger

A simple command-line **PDF Merger** built with Python. It combines multiple PDF files from a selected folder into a single PDF document.

## Features

- Merge Multiple PDFs
- Automatically Detect PDF Files
- Sort PDFs Alphabetically
- Save as a New PDF
- Simple Command-Line Interface

## Requirements

Install the required package before running:

```bash
pip install PyPDF2
```

## Run the Project

```bash
python Pdf_Merger.py
```

Example:

```text
Enter Folder Path:
C:\Users\YourName\Documents\PDFs

Output File Name:
Merged.pdf
```

## Modules Used

- Python 3
- PyPDF2

## What i learned

- External Libraries
- File Handling
- Directory Operations

- PDF Processing

> **Note:** All PDF files in the selected folder are merged in alphabetical order.
