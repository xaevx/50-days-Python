# 🔄 Sorting Algorithm Visualizer

A simple command-line **Sorting Algorithm Visualizer** built with Python. The program demonstrates how the **Bubble Sort** algorithm works by displaying the array after each comparison and swap.

## Features

- User-defined array input
- Step-by-step Bubble Sort visualization
- Displays every sorting pass
- Shows the final sorted array
- Input validation

## Run the Project

```bash
python Sorting_Algorithm_Visualizer.py
```

## Modules Used

- Python 3
- `time` module

## What i learned

- Bubble Sort Algorithm
- Lists
- Nested Loops
- Functions
- Conditional Statements
- Time Delay (`time.sleep`)
- User Input
- Exception Handling

> **Note:** This project demonstrates **Bubble Sort**, one of the simplest sorting algorithms, making it ideal for learning algorithm fundamentals.
