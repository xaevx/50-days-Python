# News Fetcher

A simple command-line **News Fetcher** built with Python that retrieves the latest news headlines using the NewsAPI.

## Features

- Fetch Top Headlines
- Country-wise News
- Publication Date
- News Source
- Simple CLI Interface
- Error Handling

## Requirements

Install the required package:

```bash
pip install requests
```

## Run the Project

```bash
python News_Fetcher.py
```

## API Key

This project uses **NewsAPI**.

1. Create a free account at:

https://newsapi.org/

2. Generate your API key.

3. Replace:

```python
API_KEY = "YOUR_API_KEY"
```

with your own API key.
