# Currency Converter

A simple command-line **Currency Converter** built with Python that converts one currency to another using real-time exchange rates.

## Features

- Convert between currencies
- Real-time exchange rates
- API Integration
- Input Validation
- Unlimited Conversions
- Simple CLI Interface

## Requirements

Install the required package:

```bash
pip install requests
```

## Run the Project

```bash
python Currency_Converter.py
```

## Example

```
From Currency : USD
To Currency   : INR
Amount        : 100

100.00 USD = 8735.42 INR
```

## Modules Used

- Python 3
- Requests
- ExchangeRate API
