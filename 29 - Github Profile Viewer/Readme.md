# Github Profile Viewer

A simple command-line **GitHub Profile Viewer** built with Python that fetches and displays public GitHub profile information using the GitHub REST API.

## Features

- View GitHub Profile
- Display Bio
- View Location
- Company Information
- Public Repository Count
- Followers & Following
- Profile URL
- Account Creation Date
- Error Handling

## Requirements

Install the required package:

```bash
pip install requests
```

## Run the Project

```bash
python Github_Profile_Viewer.py
```

## Modules Used

- Python 3
- Requests
- GitHub REST API

## What i learned

- API Integration
- HTTP Requests
- JSON Parsing
- Functions
- Dictionaries
- User Input
- Exception Handling

> **Note:** This project uses GitHub's public API, so no API key is required for basic profile lookups.
