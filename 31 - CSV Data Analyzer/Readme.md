# CSV Data Analyzer

A simple command-line **CSV Data Analyzer** built with Python and Pandas. It reads a CSV file and provides basic information and statistics about the dataset.

## Features

- Read CSV files
- Display number of rows and columns
- Display column names
- Preview first 5 rows
- Detect missing values
- Generate numerical statistics
- Handle file errors

## Requirements

Install Pandas:

```bash
pip install pandas
```

## Run the Project

```bash
python CSV_Data_Analyzer.py
```

Enter the CSV file name when prompted:

```text
Enter CSV file name: students.csv or like this (C:\Users\name\Downloads\students.csv)
```
