# Image Converter

A simple command-line **Image Converter** built with Python. It converts all supported images in a folder into another image format.

## Features

- Convert Multiple Images
- Batch Image Processing
- Supports Multiple Formats
- Preserves Original Images 
- Simple CLI Interface

## Requirements

Install Pillow before running the project:

```bash
pip install pillow
```

## Run the Project

```bash
python Image_Converter.py
```

Example:

```text
Enter Folder Path:
C:\Users\YourName\Pictures

Convert To:
PNG
```

## Supported Formats

- JPEG
- PNG
- BMP
- GIF
- WEBP
