# Maze Solver

A simple command-line **Maze Solver** built with Python. The program uses the **Depth-First Search (DFS)** algorithm with recursion and backtracking to find a path from the **Start (S)** to the **End (E)**.

## Features

- Solve a predefined maze
- Uses Depth-First Search (DFS)
- Recursive backtracking
- Displays the solved path
- Simple command-line interface

## Run the Project

```bash
python Maze_Solver.py
```

## Modules Used

- Python 3

- Depth-First Search (DFS)

### Maze Symbols

| Symbol | Meaning |
|--------|---------|
| `S` | Start |
| `E` | Exit |
| `#` | Wall |
| ` ` | Open Path |
| `.` | Solution Path |

> **Note:** This project uses a fixed maze for simplicity. The path is found using recursive Depth-First Search.
