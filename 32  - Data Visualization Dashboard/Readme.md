# Data Visualization Dashboard

A simple command-line **Data Visualization Dashboard** built with Python. The program reads data from a CSV file and generates different visualizations using Pandas and Matplotlib.

## Features

- Read CSV files
- Analyze dataset size
- Display available columns
- Bar Chart
- Line Chart
- Histogram
- Select columns for visualization
- Input validation

## Requirements

Install the required libraries:

```bash
pip install pandas matplotlib
```

## Run the Project

```bash
python Data_Visualization_Dashboard.py
```

## Modules Used

- Python 3
- Pandas
- Matplotlib
