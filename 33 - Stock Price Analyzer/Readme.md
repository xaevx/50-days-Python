# Stock Price Analyzer

A simple command-line **Stock Price Analyzer** built with Python. It fetches historical stock data and analyzes price movements using `yfinance` and `matplotlib`.

## Features

- Fetch historical stock data
- Current closing price
- Highest price
- Lowest price
- Price change percentage
- Positive/Negative trend
- Stock price chart
- Multiple time periods

## Requirements

Install the required libraries:

```bash
pip install yfinance matplotlib
```

## Run the Project

```bash
python Stock_Price_Analyzer.py
```

Enter a stock ticker when prompted:

```text
Enter Stock Ticker: AAPL
```

## Supported Periods

- 1 Month
- 3 Months
- 6 Months
- 1 Year
- 5 Years

## 🇮🇳 Indian Stocks

For Indian stocks, use the `.NS` ticker format.

Examples:

```text
RELIANCE.NS
TCS.NS
INFY.NS
HDFCBANK.NS
```
