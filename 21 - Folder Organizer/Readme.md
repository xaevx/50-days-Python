# Folder Organizer

A simple command-line **Folder Organizer** built with Python. It automatically organizes files into folders based on their file extensions.

## Features

- Organize Images
- Organize Documents
- Organize Videos
- Organize Music
- Organize Archives
- Organize Programs
- Move Unknown Files to "Others"
- Automatically Creates Required Folders

## Run the Project

```bash
python Folder_Organizer.py
```

Enter the folder path when prompted:

```text
C:\Users\YourName\Downloads
```

## Modules Used

- Python 3
- os
- shutil

## What i learned

- File Handling
- Directory Management
- Modules (`os`, `shutil`)
- Loops
- Dictionaries
- Conditional Statements
- File Extensions

> **Note:** Files are moved into categorized folders inside the selected directory. Existing folders are skipped automatically.
